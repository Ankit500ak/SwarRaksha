# Heavy ML dependencies for the PRETRAINED anti-spoofing backend
# (SWAR_SPOOF_BACKEND=pretrained). These are deliberately NOT in
# requirements.txt: the base API must boot and run the heuristic
# backend without torch. Install into the dedicated ML venv, e.g.:
#
#   python3 -m venv .venv-ml
#   .venv-ml/bin/pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
#   .venv-ml/bin/pip install -r services/ml-inference/requirements.txt \
#                            -r services/ml-inference/requirements-ml.txt
#
# The default pretrained checkpoint (AASIST, official weights) needs
# only torch — its weights (~1.3 MB) download on first use from the
# official clovaai/aasist GitHub repo. transformers/huggingface_hub
# are needed only for the experimental SWAR_SPOOF_MODEL=<hf-id>
# wav2vec2 route.
#
# Verified 2026-11-12 on this repo's dev VM (Python 3.12, CPU-only):
# torch 2.15.0+cpu, torchaudio 2.11.1+cpu, transformers 5.22.2.
# (Eval-only, not a runtime dep: piper-tts synthesises the local TTS
# eval clips in scripts/eval_pretrained.py.)
